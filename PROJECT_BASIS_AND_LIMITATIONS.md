# Project basis, assumptions and limitations

## Case-study basis

- Building type: residential apartment building.
- Configuration: 15 typical above-ground floors; basement and exact configuration are not designed.
- Structural system: reinforced-concrete frame assumed for planning illustration only.
- Scope: substructure, RCC frame, masonry, plaster, MEP, finishes and external works.
- Planning horizon: approximately 74 weeks in the level-1 illustrative schedule.
- Tools identified in the source report: Microsoft Excel and AutoCAD for conceptual drawing work.

## Inputs not provided

The source report states that no architectural or structural drawings, soil report, project specifications or vendor quotations were supplied. Therefore, all dimensions, quantities, rates, durations, progress and costs are examples for an academic portfolio exercise.

## Financial basis reconciliation

The workbook contains two separate budget bases:

- Illustrative BOQ total: ₹19.282 crore.
- Activity budget total in the Progress & Cost sheet: ₹18.263 crore.
- Difference: ₹1.019 crore.

The dashboard displays this difference explicitly. The two totals should not be treated as reconciled. Before using the workbook for a real project, map each BOQ work package to the control budget, remove overlaps/omissions, add relevant indirect costs and taxes, and validate all rates and quantities against approved documents and current quotations.

## EVM calculation basis

The sample Month-6 metrics use activity budgets as the weighting base:

- PV = Σ(activity budget × planned progress) = ₹11.318 crore.
- EV = Σ(activity budget × actual progress) = ₹10.467 crore.
- AC = sum of sample actual costs = ₹15.512 crore.
- SPI = EV / PV ≈ 0.925.
- CPI = EV / AC ≈ 0.675.

These are derived from the illustrative workbook inputs only. They are not real project KPIs and should not be represented as measured site performance. The resume draft that previously stated SPI 0.95 and CPI 0.95 is not supported by this workbook version.

## Construction and professional limitations

This case study is not a design submission or construction document. It does not include structural analysis, foundation design, geotechnical investigation, fire/life-safety design, statutory approvals, detailed MEP design, approved construction methods or site-specific engineering verification. All actual engineering and project controls require approved drawings, specifications, applicable codes/standards, vendor quotations and qualified professional review.
